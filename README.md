# Projet-Deefy_BOURREL_ELASRI

Membres du groupe : Robin Bourrel et Rayan El Asri

Pour lancer l'application deefy il faut :
1. Placer le dossier Projet-Deefy_BOURREL_ELASRI dans C:\xampp\htdocs.
2. Ouvrir XAMPP et démarrer Apache et MySQL.
3. Aller dans http://localhost/phpmyadmin/, créer une base de données nommée deefy, puis importer le fichier SQL fourni pour le TD13 sur Arche.
4. Puis ouvrir sur le navigateur la page : http://localhost/Projet-Deefy_BOURREL_ELASRI/TD13/index.php
